# Jornada Dev: do primeiro `if` à primeira aplicação

> Uma história que está sendo escrita.

Registro público dos meus estudos em programação: da lógica básica até construir aplicações completas de forma autônoma. Cada dia de estudo tem os exercícios que eu escrevi e um resumo do que aprendi, inclusive os erros e como eu os corrigi.

## Sobre mim

Sou **engenheiro da computação** (2018) em transição de carreira para o desenvolvimento de software. Antes, atuei em contabilidade, comercial e vendas, e empreendi no varejo de materiais para construção. Agora estou retomando a programação desde a base, com estudo diário e tudo documentado aqui.

## Objetivo

Ser capaz de criar sozinho uma aplicação completa, do entendimento do problema até a publicação, e atuar profissionalmente como desenvolvedor.

## Por que este repositório é público

Documentar em público é o meu compromisso com a constância. O histórico mostra a evolução real, passo a passo, sem pular as partes difíceis.

## Tecnologias

| Tecnologia | Por que escolhi |
|---|---|
| **Java 25** | Uma escolha pensando no mercado: Java é uma das linguagens mais pedidas em vagas de desenvolvimento e uma base sólida para aprender orientação a objetos. |
| **Git e GitHub** | Para versionar o código e publicar a jornada desde o começo, usando o Git pelo terminal, como no dia a dia de um desenvolvedor. |
| **VS Code** | É um editor leve e simples para começar. Quando os projetos crescerem, a ideia é migrar para uma IDE própria para Java. |

## Como rodar os exercícios
